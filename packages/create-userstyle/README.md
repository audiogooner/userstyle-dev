# create-userstyle

Scaffold a UserStyle project that depends on [`userstyle-dev`](https://www.npmjs.com/package/userstyle-dev).

```bash
npx create-userstyle my-style --origin https://example.com --name "Example Catppuccin"
```

The new directory contains `style.config.mjs`, a Catppuccin Mocha starter in `src/`, and npm scripts that call `userstyle-dev`.
